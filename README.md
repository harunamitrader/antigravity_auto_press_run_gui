# Antigravity Auto Press Run GUI

**Antigravity Auto Press Run GUI** は、AI コーディングアシスタント「Antigravity（VSCode 拡張機能）」が表示する許可確認ボタン（`Allow Once`・`Run` など）を自動でクリックし、開発の自動化をサポートするデスクトップアプリケーションです。

軽量なスクリプト版から進化したこの GUI 版は、より直感的で、かつ実行状況が視覚的にわかりやすい設計になっています。

## 💎 特徴

<img src="./public/favicon.png" width="100" align="right">

- **黒窓（コマンドプロンプト）なし**: 実行時に邪魔なデバッグ画面が表示されません。
- **直感的な操作パネル**: ON/OFF の切り替えがボタンひとつで可能です。
- **柔軟な監視インターバル**: 状況に応じて 30秒〜60分 の間で監視間隔を即座に変更できます。
- **リアルタイムログ**: 「どのボタンをいつ、どんな文脈でクリックしたか」をGUI上でリアルタイムに監視できます。
- **ポータブル設計**: インストール不要。フォルダを置くだけでどこでも動作します。

## 🚀 導入・使用方法

### 1. 動作前提：VSCode をデバッグモードで起動
本ツールは Chrome DevTools Protocol（CDP）経由で Antigravity に接続するため、VSCode 側でデバッグポートを開放しておく必要があります。

- **Windows の場合**: VSCode のショートカットを右クリックし、「プロパティ」の「リンク先」の末尾に以下を追記して起動してください。
  ` --remote-debugging-port=9222`
  （例: `"C:\...\Code.exe" --remote-debugging-port=9222`）

### 2. 本ツールの起動
1. 本リポジトリの **[Releases]** から最新のポータブル版（Zipファイル）をダウンロードします。
2. 任意の場所に解凍し、中にある **`Antigravity Auto Press Run.exe`** をダブルクリックして起動します。
3. アプリが起動したら、希望のインターバル（30秒推奨）を選択し、電源ボタンを **「ON」** にします。
